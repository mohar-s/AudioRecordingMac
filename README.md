# AudioRecordingMac
Created new app for Audio Recoding in Mac

I have completed the Assignment, I am attaching the source code and the recorded video.

What I have done :

2) user permission screen for asking permission from the user
3) Record an audio list, and show logged in status (email and name) with a signout button
4) New Recording screen: Start, pause, resume, stop options
5) Play the recorded audio with Audio Visualizer and transcription.
